## 1. 背景与目标

现有播客功能只支持粘贴单集链接后立即转写，适合一次性处理，但无法持续查看关注节目的新单集。

本期目标是把播客能力收口为一个播客工作区：

```text
订阅节目 / 导入单集
        ↓
同步节目、单集与 shownotes
        ↓
用户查看单集详情并手动选择是否获取文字稿
```

产品不承担播客播放功能。音频地址只作为后台转写输入，用户获取的核心内容是 shownotes 和文字稿。

## 2. 范围

### 2.1 本期范围

- 支持通过标准 RSS 地址订阅节目。
- 支持通过小宇宙节目主页链接订阅节目。
- 支持按节目名称或作者搜索播客节目，覆盖国内与海外 Apple Podcasts 目录，搜索结果需要用户手动点击订阅。
- 支持配置 YouTube API key 后在同一搜索入口返回 YouTube 视频结果；YouTube 结果先作为外部来源候选展示，不自动订阅。
- 搜索结果支持点击进入节目预览详情页，订阅前可查看节目介绍和最近单集。
- 首次订阅默认同步最近 50 集；支持继续加载更早单集。
- 支持手动“获取最新订阅”，一次刷新所有已订阅节目。
- 支持在节目详情页单独刷新该节目。
- 单集详情展示节目、标题、发布日期、时长、shownotes 和原始链接。
- 用户手动点击“获取文字稿”后才调用 ASR。
- 现有单集链接入口合并为播客工作区里的“导入单集”。
- 导入单集后不立即转写；识别到所属节目时提示用户是否订阅。
- 取消订阅只停止后续刷新，保留已有单集和文字稿。
- 删除节目目录及已同步单集为独立危险操作，需要二次确认；已获取的文字稿保留在“我的记录”中。

### 2.2 不在本期范围

- 播客播放、音字联动。
- 自动转写新单集。
- 每日或后台定时同步。
- 自动摘要、章节、金句、关键词。
- 多用户订阅隔离。

## 3. 核心概念

| 概念 | 定义 |
|------|------|
| 订阅节目 | 用户希望后续手动刷新新单集的节目源 |
| 单集 | 一期播客内容，转写前也作为正式内容对象存在 |
| shownotes | 节目方提供的单集介绍、时间点和相关链接 |
| 获取文字稿 | 用户主动触发 ASR，为单集创建并关联转写记录 |
| 导入单集 | 临时导入某一期单集，不默认订阅所属节目 |

## 5. 功能需求

### F1 播客工作区

- 页面包含“订阅节目”“全部单集”两个视图。
- 提供“搜索节目”“通过链接订阅”“导入单集”“获取最新订阅”操作。
- “获取最新订阅”只刷新元数据和 shownotes，不触发转写。

### F2 搜索与订阅节目

- 用户输入节目名称或作者后，系统返回可订阅的节目候选。
- 搜索结果展示来源类型、名称、作者、简介、封面、集数和订阅状态。
- 搜索本身不创建订阅、不同步单集；用户点击某个结果的“订阅”后才同步最近 50 集。
- 点击搜索结果本身进入节目预览详情页；预览页不落库、不创建订阅，只展示节目简介、来源链接和最近单集。
- 预览页提供“订阅节目”操作；订阅成功后进入正式节目详情页。
- YouTube 搜索结果展示视频标题、频道、简介、封面和发布时间，点击后打开 YouTube 原始页面；本期不把 YouTube 视频自动转为节目订阅。
- 用户输入 RSS 地址或小宇宙节目主页链接。
- 系统识别节目名称、作者、简介、封面和节目源。
- 首次同步最近 50 集。
- 同一节目重复订阅时恢复订阅状态并刷新，不重复创建。

小宇宙节目主页优先匹配节目的标准 RSS。匹配成功后按 RSS 同步；匹配失败时，降级同步小宇宙公开页面可获取的最近单集，并明确提示同步范围受限。

### F3 节目刷新与加载更多

- 全局刷新：依次刷新全部已订阅节目，返回每个节目的新增数量和失败原因。
- 单节目刷新：只刷新目标节目。
- 加载更多：每次继续同步 50 集更早内容。
- 使用节目源标识、GUID、音频地址和单集链接去重。

### F4 单集导入

- 支持直接音频 URL 和小宇宙单集网页链接。
- 导入后创建单集详情，不自动转写。
- 如识别到所属节目，展示“订阅此节目”入口。

### F5 单集详情

- 展示标题、节目名称、发布日期、时长、shownotes、原始链接。
- 文字稿状态包括：未获取、转写中、已完成、失败。
- “获取文字稿”只在未获取或失败状态可点击。
- 转写完成后在当前单集详情页展示文字稿。
- 不展示播放器，不自动生成摘要。

### F6 批量获取文字稿

- 节目详情页支持进入批量选择模式。
- 仅允许选择“未获取”或“失败”且有公开音频地址的单集。
- 支持全选当前可获取单集，单次最多发起 10 集。
- 提交前明确提示将批量调用 ASR，已完成或转写中的单集自动跳过。

### F7 取消订阅与删除

- 取消订阅后节目保留在历史内容中，但不参与全局刷新。
- 删除节目目录及已同步单集需要二次确认。
- 已产生文字稿的单集默认不随取消订阅删除。
- 删除节目目录后，已产生的文字稿仍保留在“我的记录”中。

## 6. 验收标准

1. 输入有效 RSS 后，创建节目并同步最近 50 集，单集不自动转写。
2. 输入可识别的小宇宙节目主页后，创建节目并尽量匹配 RSS；无法匹配时仍能同步公开单集并提示限制。
3. 搜索节目后只展示候选，不自动创建订阅；点击结果里的“订阅”后才同步最近 50 集。
4. 点击搜索结果标题或封面后进入节目预览详情页，仍不自动订阅。
5. 点击“获取最新订阅”后，只增加或更新单集和 shownotes。
6. 点击单集“获取文字稿”后，复用现有转写链路，完成后在单集详情展示文字稿。
7. 导入单集后不会立即产生 ASR 调用。
8. 取消订阅不会删除已有单集和文字稿。
9. 批量选择多个未获取单集后，可一次发起文字稿任务，且不会重复处理已完成单集。

## 7. 边界情况

- RSS 不规范、超时、重定向或缺少 enclosure 时，节目刷新失败但不影响其他节目。
- 搜索源没有返回 RSS feed 的结果不展示为可订阅候选。
- YouTube 搜索依赖 `YOUTUBE_API_KEY`；未配置时不返回 YouTube 结果，但不影响播客搜索。
- 预览页只展示最近单集的精简 shownotes；订阅后的正式同步保留完整 shownotes。
- 单集没有 shownotes 时展示“暂无 shownotes”。
- 单集没有公开音频地址时不可获取文字稿，并说明原因。
- 小宇宙节目无法匹配标准 RSS 时，同步数量可能少于 50。
- 同一单集通过 RSS、小宇宙页面和手动导入进入时不得重复创建。
- 转写失败后允许用户重新获取文字稿。
