## 三、🐛 发现的 Bug（模拟测试漏掉）

### B1 · 搜索结果点「订阅」→ 失败「无法识别该 RSS 节目」

- **现象**：搜索（如「tech」）返回 Apple Podcasts 结果，点「订阅」弹「订阅失败 / `{"detail":"无法识别该 RSS 节目"}`」。
- **根因**：`apps/mobile/src/app/(tabs)/podcasts.tsx:105`
  ```js
  const url = r.source_url ?? r.feed_url;  // ❌ 优先 source_url
  ```
  搜索结果是 Apple 源，`source_url` 是网页（`podcasts.apple.com/...`），后端 `fetch_catalog` 把非小宇宙链接一律当 RSS 解析（`podcast_catalog.py:fetch_rss_catalog`）→ 解析不出 title → 报错。真正的 RSS 在 `feed_url`（`...xml`）。
- **修复（client 端 1 行）**：改为 `const url = r.feed_url ?? r.source_url;`（优先真 RSS，缺失才回退）。
  - 安全性：搜索结果均带 `feed_url`；小宇宙是「粘贴链接」路径走 `source_url`，不受影响。
- **端到端验证（已做）**：用 `feed_url` curl POST `/podcasts/shows` → 成功创建 id=3「Tech Talks」→ `DELETE` 清理，订阅列表已恢复原状。
- **为何模拟测试没抓到**：mock 后端不校验 URL，照单全收；真后端 + 真 Apple 数据才暴露。
- **状态**：✅ 已修复（2026-06-21，`podcasts.tsx:105` 改为 `feed_url ?? source_url`）+ iOS 模拟器端到端复测通过（搜 tech → 订阅 TED Tech → 弹「已订阅/已同步该节目最近的单集」，后端验证创建成功后删除清理）。

### B2 · iOS 返回按钮显示「(tabs)」（仅 iOS）

- **现象**：节目详情页左上返回按钮显示「‹ (tabs)」（路由组名泄漏），应为纯箭头。
- **根因**：根 `Stack` 的 `(tabs)` 屏 `headerShown:false` 但默认 title 即路由名「(tabs)」，子页 native-stack 返回标签取父屏 title。
- **修复**：`src/app/_layout.tsx` 根 `Stack` 加 `screenOptions={{ headerBackButtonDisplayMode: 'minimal' }}`（iOS 返回按钮只显示箭头，常见模式；Android 无影响）。
- **状态**：✅ 已修复（2026-06-21）+ iOS 复测通过（返回按钮只剩「‹」）。Android 不受影响（原本就无返回文案）。

### 环境坑（iOS 篇，明天/后续复用）

- **Xcode 装了但无 iOS runtime**：`xcodebuild -downloadPlatform iOS` 下 iOS 26.5（~8.5GB）；设备 data 丢了用 `xcrun simctl create` 重建。
- **Mac 锁屏 → cliclick/screencapture 失效**（截图全黑、窗口枚举空）。解法：放弃 GUI 点击，用 **idb 无头控制**（锁屏也能点/输入；`simctl io screenshot` 不受锁屏影响）。
- **装 idb**：`pip3 install fb-idb` + `brew install facebook/fb/idb-companion`（brew 新版需 `HOMEBREW_NO_REQUIRE_TAP_TRUST=1`）。`idb connect <UDID>` 后即可 `idb ui tap x y`（**整数坐标**，点）。
- iPhone 17 Pro 逻辑 402×874 点 / 1206×2622 像素（3x）。
