# 技术说明

## 架构

```
apps/mobile (Expo/RN)
   └─ lib/api.ts(薄 client,带访问口令头)
        └─ HTTPS → 线上 Render FastAPI(/api,复用现有,零改)
               └─ Postgres / Supabase / 阿里云 ASR / Qwen(沿用现状)
```

- 移动端**不写后端**,全部读现有端点。
- 鉴权沿用 Web 的 `X-Access-Passcode`,口令存 `expo-secure-store`,401 自动回口令门。

## 技术栈

| 项 | 选择 |
|----|------|
| 框架 | Expo SDK 56 + React Native 0.85 + React 19 + TypeScript |
| 路由 | expo-router(文件式) |
| 数据 / 轮询 | @tanstack/react-query |
| 音频 | expo-audio(底部播放器 + 音字联动) |
| 本地存储 | expo-secure-store(口令 / 后端地址) |
| 图标 | @expo/vector-icons(Ionicons) |

## 复用的后端端点(全部现成,零改)

| 用途 | 方法 + 路径 |
|------|------------|
| 搜索节目 | `GET /api/podcasts/search?q=` |
| 订阅节目 | `POST /api/podcasts/shows` |
| 已订阅 / 节目详情 | `GET /api/podcasts/shows` · `/shows/{id}` |
| 刷新 / 加载更多 | `POST /api/podcasts/shows/{id}/refresh` · `/load-more` |
| 单集列表 / 详情 | `GET /api/podcasts/episodes?show_id=` · `/episodes/{id}` |
| 获取单集文字稿 | `POST /api/podcasts/episodes/{id}/transcribe` |
| 记录列表 / 文字稿 | `GET /api/recordings` · `/recordings/{id}/transcript` |

## 关键决策

- **选 Expo/RN 而非 WebView 包壳**:要真实原生手感,且代码以后能延续到上架不返工。
- **不抽 `packages/` 共享包**:Web 与 App 暂不复用,现在抽是为还没发生的复用付架构税(YAGNI);`apps/mobile` 自带薄 client。
- **默认连线上 Render**:真机无需配局域网;设置页可切本地调试。
- **临时复用访问口令**:不做正式账号(Phase 1 再做)。
- **关掉 typedRoutes**:避免动态路由字符串在纯 `tsc` 下误报;内测够用。
