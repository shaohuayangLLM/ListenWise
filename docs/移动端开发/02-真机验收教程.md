# 真机验收教程(手把手)

这是你唯一需要动手的部分。全程约 10 分钟。命令可直接复制。

---

## 0. 准备(一次性)

1. **手机装 Expo Go**:App Store(iOS)或 Google Play / 应用商店(Android)搜「**Expo Go**」,安装。
2. **手机和电脑连同一个 Wi-Fi**(扫码后手机要连到电脑上的开发服务器)。
3. 准备好你的**访问口令**(就是 Render 后端环境变量 `ACCESS_PASSCODE` 的值)。如果后端没设口令,这步可跳过。

---

## 1. 在电脑上启动开发服务器

打开终端,执行:

```bash
cd "/Users/ysh/Manual Library/ClaudeCode/个人生活/ListenWise/apps/mobile"
npx expo start
```

终端会显示一个**二维码**。保持这个终端开着(它就是开发服务器,关了 app 就连不上)。

> 提示:如果手机和电脑不在同一网段、扫码后连不上,改用隧道模式:`npx expo start --tunnel`(稍慢但更稳)。

---

## 2. 手机扫码打开 app

- **iPhone**:用系统「**相机**」App 对准二维码 → 点弹出的「在 Expo Go 中打开」。
- **Android**:打开 **Expo Go** → 点「**Scan QR code**」→ 扫码。

首次打开会编译 JS bundle,等十几秒到 1 分钟,正常。

---

## 3. 口令门

- App 默认连**线上 Render** 后端。
- 在口令门输入你的**访问口令**,点「进入」。
- 后端没设口令的话,直接留空点「进入」。

> 进去后底部应看到 3 个 tab:**播客 / 我的记录 / 设置**。

---

## 4. 逐条验收

对照打勾。每条都给了「怎么操作」和「预期结果」。

### ✅ 4.1 两端都能起来
- iOS 和 Android 各扫一次码,都能进到「播客」tab。

### ✅ 4.2 播客:搜索 → 订阅
- 在「播客」tab 顶部搜索框输入节目名(如 `声东击西`),或**粘贴一个小宇宙节目链接 / RSS 链接**,点「搜索」。
- 搜索结果里点某个节目的「订阅」。
- **预期**:提示「已订阅」,该节目出现在下方「已订阅」列表。
- 注:小宇宙没有公开搜索 API,搜不到时**优先粘贴节目链接**订阅(最稳)。

### ✅ 4.3 获取单集文字稿
- 点已订阅的节目 → 进入单集列表 → 点一集 → 看到 shownotes + 「**获取文字稿**」按钮。
- 点「获取文字稿」。
- **预期**:按钮变「转写中,完成后自动显示…」并转圈;**无需手动刷新**,转写完成后自动出现「查看文字稿」。
- 首次请求若卡 ~50s 是 Render 冷启动(见 5.1),耐心等。

### ✅ 4.4 阅读 + 音字联动(核心)
- 点「查看文字稿」进入阅读页。
- 底部播放条点 **播放**。
- **预期**:
  - 文字稿**高亮当前正在播的那句**,并**自动滚动**跟随;
  - **点某一句** → 音频跳到那句的时间;
  - 倍速按钮点一下在 `1x → 1.25x → 1.5x → 2x` 之间切换。

### ✅ 4.5 AI 解读
- 阅读页顶部切到「**AI 解读**」tab。
- **预期**:显示摘要 + 章节大纲;点章节的时间戳能跳到对应位置。
- 注:AI 解读是播客转写完成后**自动生成**的,刚转完可能要等一会儿才有。

### ✅ 4.6 转写中离开再回 / 我的记录
- 转写过程中退出单集页,过一会儿再进来 → 状态正确(仍转写中或已完成)。
- 切到「**我的记录**」tab → 已转写的单集出现在列表 → 点进去能正常阅读。

### ✅ 4.7 设置 / 口令
- 「设置」tab 能看到后端地址、口令状态。
- 点「退出 / 重设口令」→ 回到口令门(验证鉴权)。

## 5. 常见问题

### 5.1 第一次请求转圈很久(~50 秒)
Render 免费实例会休眠,第一次访问要冷启动唤醒,约 50 秒,**属正常**。之后就快了。

### 5.2 提示「网络请求失败」
- 确认口令对不对;
- 确认手机能上外网、且 Render 已唤醒(多等等再试);
- 仍不行就在「设置」里确认后端地址是默认的 Render 地址。

### 5.3 搜不到节目 / 订阅失败
小宇宙无公开搜索接口。**直接粘贴节目主页链接或 RSS 链接**到搜索框再订阅,最可靠。

### 5.4 播客音频播不了 / 转写失败
后端 ASR 下载不了**海外**音频地址。请选**国内可访问**的节目(小宇宙 CDN 没问题)。

### 5.5 想连本地后端调试(可选)
1. 电脑上起后端(注意 unset 代理):
   ```bash
   cd "/Users/ysh/Manual Library/ClaudeCode/个人生活/ListenWise/backend"
   env -u HTTP_PROXY -u HTTPS_PROXY ASR_PROVIDER=fun_asr python3 -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```
   注意 `--host 0.0.0.0`(让手机能访问)。
2. 查电脑局域网 IP(`ipconfig getifaddr en0`)。
3. App「设置」tab 把后端地址改成 `http://<电脑IP>:8000/api`,保存。手机和电脑要同 Wi-Fi。
