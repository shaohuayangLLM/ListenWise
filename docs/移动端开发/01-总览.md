# ListenWise 移动端开发 · 总览

本文件夹集中存放「移动端内测包(Phase 0)」这次开发的全部文档,你从这里一个入口就能找到所有内容,不用到处翻。

## 现在做到了哪一步

- **形态**:Expo / React Native 内测包,**iOS + Android 用 Expo Go 扫码即跑**,验证移动端手感,暂不上架。
- **打通的链路**:播客 — 搜索 / 订阅 → 单集 shownotes → 获取文字稿 → 阅读(文字稿 + AI 解读)+ 底部播放器音字联动。
- **后端**:复用现有 FastAPI,**零改动**,默认连线上 Render。
- **自测(我已跑过)**:
  - TypeScript 类型检查 `tsc --noEmit` — **0 错误**
  - 纯函数单测 `node --test` — **6/6 通过**
  - 整包打包 `expo export` — **成功(1243 模块)**,等于证明 app 能起来。
- **还差**:真机交互验收(扫码、点按、听音频、音字联动)——这部分只能在真机上做,见《02-真机验收教程》。

## 你只需要做一件事

照着 **《02-真机验收教程》** 走一遍即可。命令都给你写好了,复制粘贴就行;真机扫码那几步必须你拿手机操作(我替代不了),其余开发、自测、文档都已完成。
