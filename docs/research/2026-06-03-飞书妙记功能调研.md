# 飞书妙记（Feishu Minutes）功能特性调研报告

> 调研目的：为音频转写产品 ListenWise 的需求设计提供竞品参考。
> 调研时间：2026-06-03。信息以飞书官网、帮助中心、官方文章及第三方评测为准；存在多源冲突或仅单一来源处已标注「未确认」。

飞书妙记定位为「音视频转文字的效率工具」，覆盖会议、培训、访谈、课堂等场景，将音视频转为「可搜索、可高亮、可互动」的智能文字笔记。它不是独立 App，而是深度集成在飞书套件（会议、文档、任务、知识库）中的功能模块。

---

## 一、结构化功能清单

### 1. 音视频转文字（输入 / 格式 / 时长 / 语言）

| 维度 | 能力 | 备注 |
|---|---|---|
| 输入方式 | ① 飞书会议录制自动生成 ② 手机端发起录音 ③ 电脑端上传本地音视频文件 ④ 从飞书云文档/云盘导入文件 | 四种生成路径，会议同步是核心入口 |
| 视频格式 | MP4、MOV、AVI、FLV、WMV 等主流格式 | 来自第三方整理 |
| 音频格式 | MP3、WAV 等 | |
| 文件大小 | 单文件上限有两种说法：10GB / 4GB | **未确认**（多源冲突，疑似不同套餐或不同时期口径） |
| 识别语言 | 转写可选普通话、英语、日语、双语；多语种转写覆盖英/日/韩/法等约 12 种主流语言 + 粤语、四川话等 5 种中文方言 | 「双语」指中英混说场景 |
| 识别准确率 | 官方/第三方宣称高达 98%（基于字节跳动语音识别技术） | 营销口径，**未确认**实测 |

### 2. 实时转录

- 飞书会议支持**实时录像 + 实时字幕 + 实时翻译**三件套。
- 会议进行中边录边转，会中实时更新智能纪要，**会后秒出**完整文字稿与纪要。
- 实时字幕支持中英文互译（早期上线能力）；会议室场景需 Windows/Mac 客户端 7.0 以上版本。

### 3. 说话人区分（声纹 / 发言人）

- 自动识别不同发言者声纹特征，用**不同颜色 + 标签**标注「谁在说什么」。
- 提供「**重新识别说话人**」功能：可对已生成的录制文件重新拆分多位发言人，修正归属。
- 发言人可重命名（帮助中心《识别妙记中的说话人》专文支持）。
- 准确度无官方独立数字，混在整体 98% 口径里，**未确认**。

### 4. AI 能力（智能纪要 / 摘要 / 章节 / 待办 / 问答）

- **智能纪要/摘要**：自动生成会议总结、重点内容、封面图、全览图；「千会千面」按会议类型（产品讨论 / 进度同步 / 培训分享）差异化总结。
- **章节切分**：自动对长会议分段，每章节单独总结，支持点击跳转对应时间点。
- **待办提取**：自动提取待办事项 + 责任人，**支持原文溯源**，可一键转为飞书任务多端跟进。
- **关键词 / 风险预警**：提取要点、待办、风险点。
- **AI 问答**：可对录音内容提问（如「分析这场面试录音，怎么回答更出彩」），并基于录音生成新内容；妙记支持知识问答对话。
- **可视化生成**：自动生成流程图、时间轴、饼图、漏斗图、表格。
- **大模型**：2025–2026 升级中集成 DeepSeek R1 等大模型（第三方说法，官方文章未点名，**部分未确认**）。

### 5. 逐字稿编辑

- **音字对应播放**：点击文字定位到对应音频时间点；支持倍速播放。
- 文本可在线增删改，自动保存。
- 说话人重命名 / 重新识别。
- 时间戳定位、关键词搜索快速跳转。
- 片段裁剪：可选取特定段落创建「片段」单独分享。

### 6. 翻译

- 19 种语言互译（营销口径）；实时翻译可将发言人语言译为参会者母语。
- 转写内容支持**原文 + 译文同屏双语对照**。
- 多语一键翻译整篇妙记。

### 7. 导出与分享

- **导出格式**：飞书文档、TXT、SRT（字幕）。导出时可勾选「是否包含说话人」「是否包含时间戳」。
- 一键导出为飞书文档或飞书任务清单。
- **分享**：生成链接分享给同事/客户；**权限前置**——先定「谁能看」再定「看什么」；支持片段级分享。
- **协作**：多人实时标注、@同事、评论、拆任务。
- 注：未见明确的 Word/PDF 直接导出（需经飞书文档中转），**未确认**。

### 8. 组织管理

- 关键词搜索定位历史记录。
- 支持添加标签、标注重点整理。
- 文件夹/收藏在帮助中心有相关功能但本次未取到独立说明，**未确认**细节。

### 9. 其他亮点功能

- **术语库 / 热词**：内置多行业专业术语库 + 支持用户自定义导入术语表，提升垂直领域转写准确率。
- **高亮**：选中文字一键高亮关键信息。
- **评论**：选中文字加评论，段落右侧出现评论标签、文字下方加下划线。
- **视频字幕**：导出 SRT 可直接做视频字幕。
- 敏感词过滤：本次未检索到明确证据，**未确认**。

## 二、免费 / 付费区分

| 功能 | 计费 |
|---|---|
| 妙记基础转写 | 飞书免费版/个人版可用，但**有额度**：2024-12-03 起免费版每人每月 300 分钟「妙记语音转文字」额度，超额后会议录制不再提供文字记录 |
| 转写额度 | 飞书基础版按算力情况给体验额度；**商业版/企业版不受时长限制** |
| AI 能力（智能纪要、AI 问答、可视化等） | 需购买**飞书 AI 会员 / AI 会员 Plus**（个人版用户与企业成员可自助购买）；部分增值 |
| 实时字幕/翻译、说话人识别、编辑、导出、协作 | 属基础能力，随版本提供（具体是否全免费**未确认**） |

> 整体逻辑：**转写有时长额度墙（300 分钟/月免费），高级 AI 能力走 AI 会员订阅墙**。

## 三、对 ListenWise 三功能的可借鉴点

ListenWise 三大功能：**① 上传音视频转写 ② 播客链接转写 ③ 实时转录**。妙记的成熟设计可在以下方面具体借鉴：

**对「上传音视频转写」**
1. **音字联动播放是基线体验**：点击逐字稿任意句子跳转音频、倍速播放、搜索定位——这是妙记口碑核心，ListenWise 编辑器必须做到「文字即播放器索引」。
2. **说话人区分 + 可重命名 + 可重识别**：除自动声纹分段，务必提供「事后重新识别/拆分说话人」的纠错入口（妙记单独成文，说明这是高频痛点）；命名一次后全篇生效。
3. **自定义术语表/热词导入**：垂直场景（医疗、法律、技术）转写准确率靠热词兜底，这是低成本高感知的差异化点。
4. **导出粒度可配**：导出时让用户勾选「含/不含说话人」「含/不含时间戳」「SRT/纯文本/Word」，而非一种死格式。
5. **片段（clip）机制**：允许选取一段话单独生成片段分享/导出——比整篇分享更贴合「划重点转发」的真实使用。

**对「播客链接转写」**
6. **章节自动切分 + 点击跳转**：播客通常很长，妙记的「章节总结 + 时间点跳转」正是长音频导航的标配，应优先于平铺逐字稿。
7. **AI 问答（对内容提问）**：长播客用户不想读全文，「对这期播客提问」「这期讲了哪几个观点」是高价值入口，可基于转写做 RAG 问答。
8. **双语对照翻译**：外语播客转写后做原文/译文同屏，是明显的内容消费增量。

**对「实时转录」**
9. **边录边转 + 会后秒出**：实时字幕滚动 + 结束即出完整稿与摘要，避免「等待感」。
10. **实时翻译同屏**：实时场景下原文+译文双行展示，是跨语言会议刚需。
11. **实时高亮/标注/评论**：转录进行中即可标重点、加评论，把「听」和「记」合一。

**商业化借鉴**
12. **额度墙 + AI 订阅墙双层模型**：基础转写给免费分钟额度（培养习惯），高级 AI（摘要/问答/可视化）走订阅。ListenWise 可设计「免费 N 分钟/月转写 + AI 解读按订阅或按次」的分层。
13. **待办/纪要可一键转任务/文档**：转写产物若能直接落到用户工作流（导出文档、生成待办），留存远高于「只给一段文字」。

> 需 ListenWise 决策的点（妙记没解决或与 ListenWise 定位不同）：妙记强依赖飞书生态（导出走飞书文档、协作靠飞书 IM）；ListenWise 作为独立产品需自建分享/导出闭环（直接产 Word/PDF/SRT、独立分享链接），不能假设用户在某个套件内。
